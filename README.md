# Trickster: Sunlit Impact

A proposed direct Trickster Online fan remake with a modern painterly 2D isometric presentation. The initial target is a PC combat slice; an online world is a later goal.

Start with the [art-direction package guide](docs/art-direction/README.md), [interactive presentation](docs/art-direction/index.html), or [PDF presentation](docs/art-direction/presentation.pdf).

The package includes the visual bible, art-generation briefs, planned asset catalog, AI production and independent-review workflow, research/provenance records, an exploratory concept board, and a later Godot implementation kickoff prompt.

The current materials are proposals. Canonical reference verification, animation qualification, production assets, and gameplay implementation remain outstanding.
